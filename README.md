## About me

Hey! I'm Jacobo, and I'm studying **Multiplatform Application Development (DAM)**.

In class, I'm mostly working with Java and databases. Outside of it, I spend a lot of time learning Unity and working on my own game ideas.

I also enjoy drawing, making music and writing stories, which is probably why I keep coming back to game development. I like being able to work on both the creative and technical sides of something.

This GitHub is a mix of things I'm learning, experiments and personal projects.

---

## What I'm working on

### Kweeper

A 2D game I'm making in **Unity and C#**, inspired by Minesweeper but built around moving through a board, digging, extracting resources and deciding how much risk to take.

It's still in development, and I'm building it piece by piece.

### Personal website

I'm putting together a website with **Astro** to have a place for my games, programming projects, art and music. It's still at an early stage.

### Learning along the way

Between personal projects and my DAM coursework, I'm getting more practice with **Java, object-oriented programming, file handling, SQL and web development**.
